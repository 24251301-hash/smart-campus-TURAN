# Набор данных для СРО4

Для перехода от полностью синтетического обучения к открытому набору выбран
**Students' Academic Performance Dataset (xAPI-Edu-Data)**.

- Страница набора: https://www.kaggle.com/datasets/aljarah/xAPI-Edu-Data
- Исходная публикация: E. A. Amrieh, T. Hamtini, I. Aljarah, “Mining Educational
  Data to Predict Student's Academic Performance Using Ensemble Methods”, 2016,
  DOI: 10.14257/ijdta.2016.9.8.13.
- Объём: 480 очищенных записей.
- Используемые признаки: поднятия руки, посещения ресурсов, просмотры объявлений,
  участие в обсуждениях и категория пропусков.
- Целевая переменная: уровень успеваемости H/M/L, преобразуемый в
  «норма/средний риск/высокий риск».
- Проверенный CSV уже находится в `data/xAPI-Edu-Data.csv` (480 строк данных,
  дополненных учебными идентификаторами).

## Учебные ФИО и карточки

В начало CSV добавлены четыре поля:

- `StudentID` — стабильный код `XAPI-001`…`XAPI-480`;
- `StudentName` — синтетическое казахское ФИО;
- `StudentGroup` — группа, составленная из StageID, GradeID и SectionID;
- `NameSource` — значение `synthetic_demo`.

ФИО не являются исходными данными набора и не описывают реальных людей. Они не
используются моделью. При первом запуске приложение создаёт 480 карточек SQLite
из этих же строк. Карточки, созданные через интерфейс, получают источник
`manual_entry` и ID `MANUAL-*`.

## Подключение

1. Запустите `python server.py`.
2. Откройте `http://127.0.0.1:8000/api/dataset` и проверьте `available: true`.
3. Для обновления набора скачайте CSV с официальной страницы и замените
   `data/xAPI-Edu-Data.csv`, не изменяя заголовки столбцов.

Если файл отсутствует или не проходит проверку схемы, приложение безопасно
переходит на воспроизводимый синтетический набор и сообщает источник модели в
разделе «Аналитика».
