# СРО4: тестирование Smart Campus TURAN

## Воспроизводимые результаты

- Автоматизированные модульные, интеграционные и статические UI-проверки
  контролируют также загрузку 480 карточек и добавление нового студента.
- Нагрузочный тест на базе из 480 карточек: 100 запросов, 12 одновременных
  клиентов, 100 успешных ответов, 0 ошибок, p95 = 35,68 мс.
- Модель обучена на 480 строках xAPI-Edu-Data: 360 строк обучения и 120 строк
  тестирования; accuracy = 0,708, macro-F1 = 0,720.

Команды повторного запуска:

```bash
python -m unittest discover -s tests -v
python tests/load_test.py
python server.py
```

## Что было исправлено

1. Добавлены проверка схемы и адаптер xAPI-Edu-Data.
2. В API добавлен диагностический адрес `/api/dataset`.
3. Источник обучения и размеры выборок показаны в интерфейсе.
4. Увеличена очередь HTTP-сервера и добавлена обработка раннего разрыва связи.
5. Реализован прогрев ML-прогнозов: до исправления в холодном нагрузочном
   прогоне успешно завершалось 76/100 запросов, p95 достигал 10420,08 мс;
   после исправления и перехода на 480 карточек — 100/100 и p95 35,68 мс.

## Обязательная очная часть

Методические указания требуют 5–10 реальных участников. Их ответы нельзя
заменять автоматически сформированными отзывами. В отчёте СРО4 подготовлены
пять кодированных строк P1–P5, сценарии и анкета. Команде остаётся провести
сессии, внести фактические время, оценку и цитаты, после чего пересдать таблицу
замечаний и при необходимости выполнить ещё один цикл исправлений.
