# Smart Campus TURAN

Локальная учебная веб-система для мониторинга посещаемости, вовлечённости и
риска снижения учебной активности.

## Быстрый запуск

```bash
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:8000`. В Windows можно использовать
`start_windows.bat`.

В проект включен `data/xAPI-Edu-Data.csv` на 480 записей. В учебной копии каждой
строке назначены синтетические `StudentID`, ФИО и группа. Поэтому список и
карточки сайта теперь формируются непосредственно из строк xAPI, а не из
отдельного демонстрационного файла. Эти имена не принадлежат реальным людям.

При старте Random Forest обучается на этом наборе, а Isolation Forest на той же
матрице признаков выявляет нетипичные профили. Маршрут
`http://127.0.0.1:8000/api/dataset` показывает результат проверки набора.

На странице «Студенты» есть кнопка «Добавить студента». Новая карточка
сохраняется в SQLite, получает ID вида `MANUAL-481` и сразу проходит через обе
ИИ-модели.

## Учётные записи и роли

При первом открытии сайт показывает экран входа. На вкладке «Регистрация»
пользователь указывает ФИО, email, пароль и выбирает, кем он является:

| Роль | Дополнительное поле | Права |
|---|---|---|
| Преподаватель | Кафедра или дисциплина | полный доступ |
| Студент | Учебная группа (обязательно) | просмотр |
| Работник университета | Подразделение и должность | полный доступ |
| Другое | Кем вы являетесь (обязательно) | просмотр |

«Полный доступ» — добавление студентов и назначение консультаций. Ограничение
проверяется и в интерфейсе, и на сервере (HTTP 403).

Раздел «Мой профиль» позволяет изменить ФИО, поле роли и «О себе», сменить
пароль и выйти из аккаунта. Пароли хранятся как хеш PBKDF2-HMAC-SHA256 с
солью, сессия — случайный токен в cookie `HttpOnly; SameSite=Lax`.

Без входа API возвращает 401 (кроме `/api/health`).

**Важно для бесплатного Render:** файловая система сервиса временная, поэтому
база SQLite (включая аккаунты) очищается при перезапуске или «засыпании»
сервера. Для постоянного хранения нужен платный диск или внешняя СУБД.

## Развёртывание на Render

- Build Command: `pip install -r requirements.txt`
- Start Command: `CAMPUS_HOST=0.0.0.0 CAMPUS_PORT=$PORT python server.py`

## Проверка

```bash
python -m unittest discover -s tests -v
python tests/load_test.py
```

Подробности и обязательный протокол тестирования с пятью реальными участниками
описаны в [TESTING.md](TESTING.md). Источник и схема набора — в
[DATASET.md](DATASET.md).

## Ограничения

Прогноз демонстрационный и не должен быть единственным основанием для решений о
студенте. Перенос на данные университета требует обезличивания, проверки
смещения и повторной валидации на локальной выборке.
